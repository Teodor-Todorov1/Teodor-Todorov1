## About

I'm Teodor — a full-stack engineer and applied researcher from **Veliko Tarnovo, Bulgaria**.
I build production web applications that sit somewhere between a polished product and a research prototype: AI-assisted learning tools, payment-enabled platforms, and image-protection systems backed by error-correcting codes.

My focus is shipping software that's fast, type-safe, and honest about what it does — and writing code I'll still be proud of in a year.
