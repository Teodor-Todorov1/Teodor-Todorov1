## About

I'm Teodor — a **full-stack web developer and researcher** with **5+ years of hands-on experience**, based in Veliko Tarnovo, Bulgaria. I build complete web applications end to end, from React and Next.js front ends to Node, Flask, and Laravel back ends with SQL data layers — and I'm equally at home with the harder problems underneath: applied mathematics, security, and algorithms.

My recent work spans an **AI-powered education platform** with real-time analytics, a **Next.js marketplace** with crypto and card payments, and a **research project** that protects images using error-correcting codes. I care about clean architecture, secure authentication, and shipping things that run in production — an engineering mindset built on a decade of competitive mathematics and informatics.

- 🧩 Full-stack across **three ecosystems** — JavaScript/TypeScript (React, Next.js, Node), Python (Flask), and PHP (Laravel)
- 🤖 Built **AI-driven and real-time** features — OpenAI quiz generation, Socket.IO notifications
- 💳 Integrated **production payments** — Stripe (cards) and Coinbase Commerce (crypto)
- 🔐 Applied-research focus — **steganography & error-correcting codes** (Reed–Solomon, Hamming)
- 🎓 Studied **C# / .NET** at SoftUni (Software University)

## 🚀 Featured Projects

### [AcademIQ](https://github.com/Teodor-Todorov1/AcademIQ) — AI-powered education platform
A full-stack learning platform where teachers generate **AI-written quizzes**, manage assignments, and track student performance through graphical analytics — with **real-time notifications**, role-based access for students/teachers/admins, secure file uploads, and PDF reporting.

**Stack:** React · Redux Toolkit · Node.js · Express · TypeScript · MySQL · Sequelize · Socket.IO · OpenAI API · JWT

[![Source Code](https://img.shields.io/badge/Source_Code-30363D?style=flat-square&logo=github&logoColor=white)](https://github.com/Teodor-Todorov1/AcademIQ)

### [Watermark-Studio](https://github.com/Teodor-Todorov1/Watermark-Studio) — image protection via error-correcting codes
A Flask platform that embeds **invisible digital watermarks** into images and recovers them reliably using a combination of **Reed–Solomon and Hamming(7,4)** error-correcting codes, with LSB and DWT-DCT embedding for robustness against tampering.

**Stack:** Python · Flask · NumPy · OpenCV · Firebase Auth

[![Live Demo](https://img.shields.io/badge/Live_Demo-A371F7?style=flat-square)](https://wmstudio-2a1b1e4d71b9.herokuapp.com/) [![Source Code](https://img.shields.io/badge/Source_Code-30363D?style=flat-square&logo=github&logoColor=white)](https://github.com/Teodor-Todorov1/Watermark-Studio)

### [DEVT-MAG](https://github.com/Teodor-Todorov1/DEVT-MAG) — Next.js marketplace with dual payments
A Next.js content marketplace with distinct **buyer and seller roles**, integrating **Stripe** for card payments and **Coinbase Commerce** for cryptocurrency checkout.

**Stack:** Next.js · React · TypeScript · Stripe · Coinbase

[![Live Demo](https://img.shields.io/badge/Live_Demo-A371F7?style=flat-square)](https://project-pink-chi.vercel.app/register) [![Source Code](https://img.shields.io/badge/Source_Code-30363D?style=flat-square&logo=github&logoColor=white)](https://github.com/Teodor-Todorov1/DEVT-MAG)

### [MindGame](https://github.com/Teodor-Todorov1/MindGame) — bilingual educational game
An online educational memory game (**Bulgarian/English**) with a timed leaderboard and a full **admin module** for managing facts, users, roles, and localization.

**Stack:** Laravel · PHP · JavaScript · jQuery · Bootstrap · MySQL

[![Live Demo](https://img.shields.io/badge/Live_Demo-A371F7?style=flat-square)](https://mindgame.vtbg.eu/) [![Source Code](https://img.shields.io/badge/Source_Code-30363D?style=flat-square&logo=github&logoColor=white)](https://github.com/Teodor-Todorov1/MindGame)
